## Lessons Learned
- Unhandled top-level errors in client-side singleton initializers (e.g. Supabase client) can break module bundling and SSR pre-rendering even before the app starts.
- Hardcoded local paths and unauthenticated execution in Next.js API routes prevent safe serverless deployments; always sanitize execution contexts with environment variables and token verification.
- Keeping MCP configs synchronized across configuration roots ensures consistent tooling availability across IDE restarts and agent sessions.
